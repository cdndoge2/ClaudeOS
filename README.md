# ClaudeOS
Doge's ClaudeOS, Basic operating system made entirely by Claude Sonnet 5.

===================================================

V1 - Broken, useless.
V1.1 - First functioning version, just a boot test.
V2 - Basic timer test.
V3 - First build with a shell and basic commands.
V4 - Added memory
V5 - Added persistent storage(ish), notepad, calculator

===================================================

This has been tested and recommend to be used on QEMU. Latest build version 5 has persistent storage so long as the QEMU window stays open, the "reboot" command does indeed reboot the OS and the files do stay, however, once the QEMU window is closed that data gets reset.
The end goal of this project is to have a basic sub-1MB TUI like operating system with basic games and apps, such as Blackjack, 2048, Snake, Notepad, File Manager, etc.
